# Gokul Portfolio

A simple static portfolio built with:

- HTML
- CSS
- Vanilla JavaScript

## Run locally

Open `index.html` directly in a browser, or use any simple local server.

## GitHub Pages

Push the project to a GitHub repository and enable **GitHub Pages** from the repository's Pages settings.

## Before publishing

Replace:

- `#` Resume link
- `#` Behance link
- `#` case study links
- `assets/images/pawtrain-preview.png` with the final exported PawTrain mockup if available
- Trainer Dashboard placeholder with the final project preview when available
